## 🚀 Instalación en Blogger

1. En Blogger ve a **Tema**
2. Haz clic en la flecha ▼ junto al botón naranja **PERSONALIZAR**
3. Elige **"Crear copia de seguridad"** para guardar tu tema actual
4. Abre el mismo menú y elige **"Restablecer"**
5. Sube el archivo `steamdownloader2026-plantilla.xml`

⚠️ Tus entradas NO se borran, solo quedan ocultas. Para volver a tu tema anterior,
sube la copia de seguridad que descargaste.
